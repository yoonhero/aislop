# HiBulb for Zotero

Zotero 10.0용 하이라이트와 여백 메모 플러그인. Zotero 10.0.9에서 PDF, 웹 스냅샷, EPUB으로 확인했다.

- 리더의 형광펜과 노트 도구를 전구와 메모 버튼으로 바꾼다. 전구를 켠 뒤 드래그하면 Zotero의 선택 엔진으로 하이라이트를 생성한다.
- 선택한 텍스트·주석 옆 툴바에서 색상, 연결 메모, 삭제를 조작한다. 색상 버튼은 같은 툴바 안에서 팔레트로 전환한다.
- 메모는 본문의 주석 좌표에 붙는다. 이동 핸들을 드래그하거나 방향키로 옮기고, 접기 버튼으로 닫는다. 내용을 클릭하거나 Enter를 눌러 편집한다.
- 메모 크기와 글씨, 주석에서 떨어진 거리는 문서 배율에 함께 맞춘다. PDF의 가로 위치도 페이지를 기준으로 저장하여 확대·축소와 가로 스크롤에서 종이에 붙인 위치를 유지한다.
- 메모를 문서의 스크롤 영역에 배치해 관성 스크롤 중에도 본문과 함께 움직인다. 화면 밖 메모의 편집 위치는 보관하고, 편집 중인 메모는 확대·축소 중에도 입력창을 유지한다.
- 포스트잇은 옅은 종이색과 작은 이동·접기 표시만 사용한다. 웹 스냅샷의 스타일과 입력 이벤트는 메모에 영향을 주지 않는다.
- Markdown과 LaTeX 수식을 지원한다. Markdown 모듈은 메모를 표시할 때, KaTeX 모듈은 수식이 있을 때 불러온다.
- 네이티브 스크롤바 옆에 주석 위치를 얇은 색상 선으로 표시한다. 메모가 있는 선은 길게, 현재 화면의 선은 진하게 표시한다. 마우스나 키보드 포커스로 원문·메모를 미리 보고 클릭하여 이동한다. 가까운 주석은 묶어서 목록에서 선택한다.
- 하이라이트·메모 내용은 Zotero 주석으로 저장되어 기존 검색, 동기화, 주석 내보내기, 실행 취소를 사용한다. 포스트잇 배치·접힘 상태는 기기별 Zotero 설정에 저장한다. 읽던 위치는 Zotero 리더가 저장한다.

Zotero의 도구 → 플러그인 → 톱니바퀴 → 파일에서 플러그인 설치에서 XPI를 선택한다. PDF 리더의 네이티브 메뉴와 사이드바도 계속 사용할 수 있다.

```sh
python3 zotero-hibulb/build.py dist
```

Markdown/KaTeX 번들은 같은 저장소의 `pastel-pen/note-renderer`에서 생성한다. 패키지의 vendor 디렉터리에 해당 번들의 라이선스 고지가 포함되어 있다.

리더의 주석 관리와 좌표 변환에 Zotero 내부 API를 사용하므로 호환 범위를 검증한 10.0.x로 제한한다. 읽기 모드·분할 창 등 새 리더 구현이 바뀌면 다시 검증해야 한다. 플러그인을 비활성화하면 추가 UI와 등록한 처리기를 정리하고 기본 리더 컨트롤을 복원한다.
