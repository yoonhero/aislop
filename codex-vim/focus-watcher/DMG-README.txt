CODEX VIM FOCUS

1. Drag “Codex Vim Focus” into “Applications”.
2. Open Codex Vim Focus from Applications.
3. Click the VIM menu-bar item.
4. Choose “Setup Everything”.
5. Grant Accessibility permission when macOS asks.

Requirements:
- macOS 13 or newer
- Official Codex desktop app in /Applications
- Karabiner-Elements

Codex Vim is an unofficial macOS utility.
